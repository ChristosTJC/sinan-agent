# 嵌入式知识检索

## 触发条件

用户提出以下任一问题时触发：
- 芯片手册参数查询（"STM32F407 的 TIM1 挂载在哪条总线"、"ESP32-S3 的 RTC 时钟源有哪些"）
- 通信协议参考（"I2C 快速模式的时序要求"、"CAN 波特率怎么算"）
- 传感器数据手册查询（"MPU6050 WHO_AM_I 寄存器值是多少"、"VL53L0X 最大测距距离"）
- 寄存器地址与位域查询（"USART1 的 BRR 寄存器地址"、"GPIO MODER 寄存器位域定义"）
- 错误码检索（"HAL_I2C_ERROR_AF 是什么原因"、"ESP_ERR_TIMEOUT 怎么解决"）
- 引脚功能查询（"STM32F103C8T6 PA2 有哪些复用功能"）
- 协议时序文本化展示
- 计算公式验证（"115200 波特率下 STM32F4 的 USARTDIV 怎么算"）

## 核心能力

### 1. 芯片手册关键参数查询

**查询分类与示例**：

**存储器映射查询**：
```
问：STM32F407VGT6 的 Flash 和 RAM 基址？
答：Flash: 0x08000000 (1MB)，RAM: 0x20000000 (128KB SRAM1) + 0x2001C000 (64KB CCM RAM)
```

**总线拓扑查询**：
```
问：TIM1 挂载在哪条总线？
答：TIM1 挂载在 APB2 上，最大时钟频率 168MHz (APB2 定时器时钟 = APB2 × 2 当 APB2 预分频 ≠ 1)
```

**外设时钟源查询**：
```
问：STM32F4 的 USART1 时钟源可选哪些？
答：
- PCLK2 (APB2, 默认)
- SYSCLK
- HSI (16MHz)
- LSE (32.768kHz)
选择通过 RCC_DCKCFGR2 寄存器的 USART1SEL 位配置
```

**中断向量表查询**：
```
问：EXTI Line 0 的中断号是多少？
答：EXTI0_IRQn = 6 (STM32F4 系列)
中断向量表偏移：0x0000_0058
```

### 2. 通信协议参考

**I2C 协议参数速查**：

| 参数 | 标准模式 (Sm) | 快速模式 (Fm) | 快速增强模式 (Fm+) | 高速模式 (Hs) |
|------|-------------|-------------|-------------------|-------------|
| SCL 时钟频率 | 0-100 kHz | 0-400 kHz | 0-1 MHz | 0-3.4 MHz |
| 上升时间 t_r (max) | 1000 ns | 300 ns | 120 ns | 160/80 ns |
| SDA 数据建立时间 t_SU;DAT | 250 ns | 100 ns | 50 ns | 10 ns |
| START 保持时间 t_HD;STA | 4.0 μs | 0.6 μs | 0.26 μs | 0.16 μs |
| STOP 建立时间 t_SU;STO | 4.0 μs | 0.6 μs | 0.26 μs | 0.16 μs |
| 总线电容 (max) | 400 pF | 400 pF | 550 pF | 400/100 pF |
| 上拉电阻典型值 (3.3V) | 4.7 kΩ | 2.2 kΩ | 1.0 kΩ | — |
| 低电平噪声容限 | 0.3VDD | 0.3VDD | 0.3VDD | 0.1VDD |

**上拉电阻精确计算**：

```
Rp(min) = (VDD - V_OL,max) / I_OL
       = (3.3 - 0.4) / 0.003     = 967 Ω     (取 I_OL=3mA)
Rp(min) = (3.3 - 0.4) / 0.006    = 483 Ω     (取 I_OL=6mA)

Rp(max) = t_r / (0.8473 × C_b)
       = 300e-9 / (0.8473 × 400e-12)  = 885 Ω    (快速模式, 300ns 上升时间)
       = 1000e-9 / (0.8473 × 400e-12) = 2953 Ω   (标准模式, 1000ns 上升时间)

实际选择: max(Rp(min), 标准值) 与 Rp(max) 之间
典型安全值: 标准模式 4.7kΩ, 快速模式 2.2kΩ
```

**SPI 参数速查**：

| 参数 | 约束 |
|------|------|
| SCK 最大频率 | min{MCU_SPI_CLK/2, 从设备手册最大值} |
| Mode 0 (CPOL=0, CPHA=0) | SCK 空闲低，第一个边沿(上升)采样 |
| Mode 1 (CPOL=0, CPHA=1) | SCK 空闲低，第二个边沿(下降)采样 |
| Mode 2 (CPOL=1, CPHA=0) | SCK 空闲高，第一个边沿(下降)采样 |
| Mode 3 (CPOL=1, CPHA=1) | SCK 空闲高，第二个边沿(上升)采样 |
| t_CS_SCK (CS 到第一个 SCK) | 通常 ≥ 1/2 SCK 周期 |
| t_SCK_CS (最后一个 SCK 到 CS 释放) | 通常 ≥ 1/2 SCK 周期 |
| 数据位宽 | 8-bit 或 16-bit（Motorola 格式），部分设备支持 4-32 bit |
| LSB/MSB 优先 | 绝大多数为 MSB 优先 |
| NSS 管理 | 硬件 NSS（自动拉低/释放）vs 软件 NSS（GPIO 手动控制） |

**UART 波特率计算（STM32F4 为例）**：

```
USARTDIV = f_CK / (16 × BaudRate)

示例: f_CK = 84MHz (APB2), BaudRate = 115200
USARTDIV = 84000000 / (16 × 115200) = 45.572

DIV_Mantissa = 45 (整数部分写入 BRR[15:4])
DIV_Fraction = round(0.572 × 16) = 9 (小数部分写入 BRR[3:0])
即 BRR = 0x2D9

实际波特率 = 84000000 / (16 × 45.5625) = 115205
误差 = |115205 - 115200| / 115200 = 0.004%  ✓ (远小于 2%)
```

**CAN 波特率计算**：

```
CAN 位时间 = 1 / BaudRate
         = Tq × (1 + BS1 + BS2)

Tq = (BRP + 1) / f_CAN_CLK

示例: f_CAN_CLK = 42MHz (APB1), 目标 1Mbps
位时间 = 1μs = Tq × (1 + BS1 + BS2)

取 BRP = 2 → Tq = 3/42MHz = 71.4ns
N_Tq = 1μs / 71.4ns ≈ 14 Tq

分配: BS1 = 11, BS2 = 2, SJW = 1
1 + 11 + 2 = 14 Tq = 14 × 71.4ns = 1.0μs = 1Mbps ✓

采样点 = (1 + BS1) / (1 + BS1 + BS2) = 12/14 = 85.7% (推荐范围 75-90%)
```

### 3. 传感器数据手册检索

**常用传感器速查**：

**MPU6050 / MPU9250 (TDK InvenSense)**：
| 参数 | 值 |
|------|-----|
| I2C 地址 | 0x68 (AD0=GND) 或 0x69 (AD0=VDD) |
| WHO_AM_I 寄存器 | 0x75 → 应返回 0x68 (MPU6050) 或 0x71 (MPU9250) |
| 陀螺量程 | ±250/±500/±1000/±2000 °/s (寄存器 0x1B) |
| 加速度计量程 | ±2/±4/±8/±16 g (寄存器 0x1C) |
| 采样率 | 由 SMPLRT_DIV (0x19) 控制, f_sample = 1kHz / (1 + SMPLRT_DIV) |
| DLPF 带宽 | 寄存器 0x1A 设置: 0=260Hz, 1=184Hz, 2=94Hz, 3=44Hz, 4=21Hz, 5=10Hz, 6=5Hz |
| 上电初始化 | 写 0x00 到 PWR_MGMT_1 (0x6B) 唤醒，等待 PLL 稳定 100ms |
| 数据转换 | accel_g = raw × FS / 32768, gyro_dps = raw × FS / 32768 |
| 常见坑 | 直接断电再上电可能卡死 → 在 PWR_MGMT_1 写 0x80 做 Device Reset |

**VL53L0X (ST ToF 测距)**：
| 参数 | 值 |
|------|-----|
| I2C 地址 | 0x29（默认，出厂配置），XSHUT 拉低可改址 |
| 测量范围 | 30mm ~ 2000mm（白色目标，暗环境） |
| 精度 | ±3% (近距离), ±5-10% (远距离) |
| XSHUT 引脚 | 必须拉高才能工作，用于多传感器分时使能 |
| 上电时序 | AVDD → AVDDVCSEL 之间需等待 ≥ 1.2ms |
| 初始化流程 | 上电 → 等待 boot → 加载校准数据 → 配置测量参数 → RefSPAD 校准 → 开始测距 |
| 常见坑 | 盖片透过率不足导致远距失效 → 需提高 VCSEL 驱动电流或更换高透盖片 |

**BME280 (Bosch 环境传感器)**：
| 参数 | 值 |
|------|-----|
| I2C 地址 | 0x76 (SDO=GND) 或 0x77 (SDO=VDD) |
| ID 寄存器 | 0xD0 → 应返回 0x60 |
| 温度补偿参数 | 从寄存器 0x88-0x8D, 0x8E-0xA1 读取 |
| 温度计算 | 使用 Bosch 补偿算法，32-bit 有符号整型运算（禁止用浮点近似，会导致 >0.5°C 误差） |
| 湿度补偿参数 | 从寄存器 0xE1-0xE7 读取 |
| 最大采样速率 | 1Hz (温+湿+压, 超低功耗模式) ~ 180Hz (仅温度, 低功耗模式) |
| 常见坑 | 未等待测量完成 (status 寄存器 bit 3) 就读数据 → 读到上次的旧数据 |

### 4. 错误码检索与解决方案

**STM32 HAL 库常见错误码**：

| 错误码 | 含义 | 常见原因 | 排查步骤 |
|--------|------|----------|----------|
| HAL_OK (0x00) | 正常 | — | — |
| HAL_ERROR (0x01) | 通用错误 | 配置参数错误或硬件异常 | 检查初始化参数合法性 |
| HAL_BUSY (0x02) | 外设忙 | 上笔传输未完成 | 等待操作完成或调用 Abort() |
| HAL_TIMEOUT (0x03) | 超时 | 外设无响应 | 检查设备是否上电、总线是否连通、中断是否开启 |
| HAL_I2C_ERROR_AF (0x04) | I2C ACK Failure | 从设备 NACK | 检查地址是否正确、设备是否就绪 |
| HAL_I2C_ERROR_BERR (0x02) | I2C 总线错误 | SDA 电平异常跳变 | 检查上拉电阻、检查是否有其他主机 |
| HAL_I2C_ERROR_OVR (0x08) | I2C 溢出 | 主机没有及时读 DR | 使用 DMA 或提高 I2C 中断优先级 |
| HAL_I2C_ERROR_DMA (0x10) | I2C DMA 错误 | DMA 传输异常 | 检查 DMA 通道和内存对齐 |
| HAL_SPI_ERROR_UDR (0x04) | SPI 下溢 | 从模式数据未准备好 | 增加预加载 |
| HAL_SPI_ERROR_OVR (0x02) | SPI 上溢 | 主模式读 DR 不及时 | 使用 DMA |
| HAL_TIMEOUT (I2C) | 等待 SB/ADDR/BTF 位超时 | I2C 外设未响应 | 用示波器抓 SDA/SCL、复位 I2C 外设 |

**ESP-IDF 常见错误码**：

| 错误码 | 含义 | 排查方向 |
|--------|------|----------|
| ESP_OK (0) | 正常 | — |
| ESP_FAIL (-1) | 通用失败 | 检查初始化参数 |
| ESP_ERR_TIMEOUT (-2) | 操作超时 | FreeRTOS 信号量超时或硬件超时 |
| ESP_ERR_NO_MEM (0x101) | 内存不足 | 检查堆剩余 (heap_caps_get_free_size) |
| ESP_ERR_INVALID_ARG (0x102) | 无效参数 | 指针为空或参数超出范围 |
| ESP_ERR_INVALID_STATE (0x103) | 状态异常 | 在错误的初始化状态下调用 |
| ESP_ERR_INVALID_SIZE (0x104) | 大小错误 | 缓冲区大小不足 |
| ESP_ERR_NOT_FOUND (0x105) | 未找到 | 查询的资源不存在 |
| ESP_ERR_NOT_SUPPORTED (0x106) | 不支持 | 该芯片不支持此功能 |
| ESP_ERR_WIFI_BASE (0x3000+) | WiFi 错误基址 | 通常是 ESP_ERR_WIFI_NOT_STARTED 等 |

### 7. 外设寄存器快速查询

**示例——查询 STM32F4 GPIO 寄存器**：
```
GPIOA 基址: 0x40020000

偏移量 | 寄存器 | 访问 | 复位值 | 描述
0x00   | MODER  | R/W  | 0xA8000000 | 端口模式 (00=IN, 01=OUT, 10=AF, 11=ANALOG)
0x04   | OTYPER | R/W  | 0x00000000 | 输出类型 (0=推挽, 1=开漏)
0x08   | OSPEEDR| R/W  | 0x00000000 | 输出速度 (00=低速, 01=中速, 10=快速, 11=高速)

0x14   | ODR    | R/W | 0x00000000 | 输出数据寄存器
```

## 工具要求

- 查阅芯片参考手册和数据手册——优先读取本地文件
- 当本地未命中时，给出获取途径（STM 官网/Espressif 文档/传感器厂商官网）
- 对于无手册或手册不完整的情况，明确告知信息来源的可靠性和不确定性

## 工作流程

1. **解析查询意图**：识别是手册查询、协议参考、传感器参数、寄存器查询还是错误码诊断
2. **知识检索**：从当前技能文档和本地知识库中匹配信息
3. **计算验证**：对公式类查询进行数值验证，标注实际误差
4. **手册指导**：当信息不在本地时，给出获取目标手册的精确路径

## 安全约束

- 引用的寄存器地址和位域信息必须是目标芯片准确的。如果无法确认芯片具体型号或修订版本，明确标注"请以芯片对应版本参考手册为准"
- 时序参数引用自标准规范，但实际项目需根据具体设备的容忍度做验证。给出理论值的同时标注"实际可能需要调整"
- 不要仅凭记忆给出手册关键参数——如果本地没有对应手册，指导用户如何自行获取
